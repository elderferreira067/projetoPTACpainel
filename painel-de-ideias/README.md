# Painel de Ideias

Projeto desenvolvido em React para cadastrar, visualizar, concluir e remover ideias.

## Funcionalidades

- Adicionar novas ideias
- Impedir o cadastro de ideias vazias
- Listar todas as ideias
- Marcar ideias como concluídas
- Remover ideias
- Mostrar o total de ideias
- Mostrar a quantidade de ideias concluídas

## Tecnologias utilizadas

- React 18
- Vite
- JavaScript
- CSS
